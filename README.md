# 在途

面向同行旅行者的共享行程、随手记账与旅途照片应用。

## 功能

- 按旅行日期横向浏览多日行程
- 一次导入多天日程
- 交通、住宿、餐饮、门票和其他开销实时汇总
- 账单记录修改与二次确认删除
- 同行共享行程、账单和照片
- 手机原图上传前自动优化
- 多图邮票墙与单张照片删除
- 一键将随拍与每日行程生成 PNG 打卡长图
- 当前旅程保存为可再次打开的历史快照

## 同步与存储

- D1 保存旅程、日期、日程、账单、照片元数据和历史快照
- R2 保存用户上传的照片文件
- 页面每 5 秒刷新共享状态；写入成功后立即刷新当前页面
- 当前版本使用共享旅程码 `TRIP-START`，适合一组同行者共同使用

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000/`。

## 验证

```bash
npm run build
npm test
```

项目通过 `.openai/hosting.json` 声明 D1 和 R2 绑定。发布后由托管环境提供真实共享存储。
